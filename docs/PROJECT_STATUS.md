# Project Status and Scientific Boundaries

## Canonical release

`0.4.0-canonical-reconstruction`

This release is intended to be a trustworthy project base, not a claim that every
historical result is now reproduced by one executable.


## Retraction status

Retraction R-001 applies to the v5.0 semantic consequence-governance demonstration and
downstream claims that inherit its answer-bearing evidence helper. It does **not** retract the
proposal-generator + evidence-arbitration architecture as a design, and it does not affect the
memory runtime.

Surviving v5.0 measurement: semantic top-1 0.2609375; top-5 coverage 0.7671875.

See `docs/RETRACTION_LEDGER.md`.

### v4.x boundary

R-001 does not reach backward into v4.x. v4.0-v4.2 use corpus-statistic evidence; v4.3-v4.8 use non-oracular measured consequence/factor evidence; v4.9 is a separate randomized binary symmetric-decoy consequence-arbitration benchmark.

However, the preserved v4.0-v4.8 headline evidence is **local smoke/proxy evidence**, not preserved full Shakespeare/KJV runs, and several later notebooks use only three seeds. See `docs/V4_EVIDENCE_BOUNDARIES.md` before citing those results.

## Claims this project does support

Within the supplied research artifacts, the project can document that:

- a seven-role fault-coupled search selected confidence + P/Q parity in its reported
  held-out battery;
- behavioral memory experiments were built around working + redundant durable banks;
- the architecture repeatedly uses explicit uncertainty states rather than forced
  answers;
- objective verification is treated as qualitatively stronger than repeated source
  agreement;
- learned source dependence and latent common-cause structure were separately tested;
- developmental experiments allow internal structure/capacity to earn permanence
  through measured consequences.

## Claims this project does not make

- AGI
- consciousness
- fully autonomous architecture invention
- causally identified latent factors
- production readiness
- benchmark equivalence for reconstructed modules unless separately verified
