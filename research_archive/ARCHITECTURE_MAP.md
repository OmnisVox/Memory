# Architecture map

## A. Persistent dynamical memory
A slow complex field `chi` stores phase-sensitive structure. Recall is a restorative coupling from
stored memory back into the active state. The scalar/history lane can coexist with the complex lane.

## B. Addressable multi-slot bank
Multiple independent memory slots store a dynamical template plus a compact transparent address
vector and usage metadata. The validated vortex-family address descriptor was a 12-D
core-geometry + global-moments representation.

Ambiguous addresses return **HOLD / unresolved** rather than forcing a selection.

## C. Stability–plasticity controller
Recall and learning have distinct rates/cadences. Normal operation favors fast recall and slow
learning. Source-of-surprise diagnostics can temporarily freeze writing, freeze recall, or use
symmetric repair depending on which source appears damaged.

## D. Selective consolidation
New observations first enter provisional memory. Permanent storage is a decision:

- `INCLUDE`: enough evidence/value to allocate or replace a permanent slot
- `EXCLUDE`: redundant, inconsistent, or not worth consolidation
- `HOLD`: insufficient evidence; remain provisional

HOLD is distinct from forgetting.

## E. Consequence-aware value
Candidate value is decomposed rather than hidden in one opaque score. The research lineage includes
recurrence, stability, novelty, measured downstream utility, consequence severity/criticality, and
interference/replacement cost.

Recent utility can adapt to regime changes. Successful retrieval can reconsolidate slowly.

## F. Trust and evidence graph
Reports are calibrated against later verified consequences. The system can track:

- per-source reliability
- signed source bias
- trust-weighted/debiased utility
- causal provenance groups
- learned source-dependency/redundancy
- verifier reliability
- common-cause risk

Low-confidence value remains `VALUE_UNRESOLVED`; the candidate stays HOLD.

## G. Structural/developmental controller
The system does not need every representational feature or connection to remain permanent.

The lineage contains deterministic consequence-driven selection at several scales:

1. slot/configuration search (v3.15 result preserved downstream)
2. leave-one-edge-out direct value and coalition-aware second chances (v3.8)
3. factor birth/pruning and an informational soft capacity wall (v10)
4. action-conditioned structural induction from experienced state/action/consequence tuples (v11)

This is self-structuring **within an engineered substrate**, not unconstrained invention of arbitrary
new algorithms.

## H. Relational identity lane
Geometric similarity and identity are kept distinct. A sparse relational sidecar supports exact
identity continuity and multi-hop structural traversal while the continuous/geometric memory remains
independent.

## I. Semantic consumer layers
The v4/v5 lineage adds semantic proposal machinery, identity binding, variable-depth path traversal,
endogenous stopping, consequence arbitration, coreference repair, progressive recall, and narrow
ontology growth.

These are optional consumers/extensions of the memory substrate, not prerequisites for the core
memory package.
