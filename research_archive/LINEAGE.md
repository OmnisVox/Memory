# Lineage map

## Early memory primitive
**v3.1 complex-memory patch**
- Replaced the insufficiency of scalar intensity history for phase/chirality with a slow complex
  memory field.
- Kept explicit ablations for no feedback, instantaneous memory, frozen memory, no diffusion, and
  phase erasure.

## Memory-bank maturation
**Multi-slot study**
- Turned a one-slot recency memory into an addressable memory bank.
- Ablated a 28-D candidate descriptor down to a robust 12-D address vector.
- Added corruption-aware preprocessing, confidence margins, ambiguity refusal, and finite capacity.

**Memory timescale / interference study**
- Separated recall from write cadence.
- Added source-of-surprise triage for active-state versus memory damage.

**Selective commit**
- Added provisional candidates and explicit INCLUDE / EXCLUDE / HOLD.
- Dramatically reduced permanent write churn in the controlled benchmark.

**Consequence/trust patches**
- Added measured downstream utility, critical consequences, interference costs, slow
  reconsolidation, source reliability, bias correction, provenance constraints, dependency
  discounting, and unresolved-value behavior.

## Structural self-selection
**v3.15 seven-slot search**
- Original search bundle not recovered in this archive.
- Downstream v3.8 records the held-out fault-coupled winner as
  `confidence + parityP + parityQ`.

**v3.8 parity + coalition structural plasticity**
- Connections begin provisional.
- Direct edge consequence is tested by leave-one-edge-out ablation.
- Weak individual recurrent edges can receive a coalition second chance when joint value is
  super-additive.
- Parity is explicitly hand-designed error management, not claimed as spontaneously discovered.

**Developmental v10**
- Starts with one factor.
- Factors grow/prune from experienced predictive consequences.
- Representation capacity becomes a soft sidewall whose pressure changes with informational drag.

**Developmental v11**
- Adds action-conditioned consequence structure.
- Cross-fits action models from the agent's own experienced state/action/consequence tuples.
- Birth/prune pressure can depend on distinctions that matter because different actions lead to
  different consequences.

## Semantic / relational line
**v4.0–v4.4**
- Deterministic HOLD/evidence/selective-replay/parity framework moves into semantic transfer.
- v4.4 separates positive consequence value from novelty/interference and introduces adaptive
  replacement pressure.

**v4.5**
- Separates consolidation value from retrieval/access value.
- Adds compact identity graph beside raw-template memory.

**v4.6–v4.7**
- Tests generic exact-identity traversal across increasing path depth.

**v4.8**
- Removes supplied traversal depth and chooses stopping point from structural evidence.

**v4.9**
- Tests structurally symmetric alternatives where only downstream consequence agreement can choose.

**v5.1**
- Semantic model proposes relation + entity/coreference parses; downstream consequences govern trust.

**v5.3+**
- Progressive evidence-gated recall, learned mention-role proposal, and narrow consequence-grounded
  prototype growth.

## Reconstruction rule

Do not pick one version number and call it "the memory architecture."

The standalone memory project should merge only mechanisms that:
1. solve distinct problems,
2. survived their own controls,
3. do not double-count the same evidence,
4. preserve unresolved states instead of forcing guesses,
5. retain explicit audit paths.
