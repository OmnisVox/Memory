# Adrianic v3.20 — Learned Dependency Graph

The main controller is not given provenance labels. Sparse verified residual histories are used to estimate pairwise error correlation. Sources with correlation > 0.72 are linked and connected components become inferred evidence families. Each inferred family receives at most one source-equivalent voting budget. Manual provenance is retained only as an oracle comparison. Tests include hidden alias collusion, common-mode corruption, a mid-run dependency reversal, sparse-verification sweeps, and downstream durable-memory junk-write rates.
