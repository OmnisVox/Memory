# Adrianic v3.16 — Behavioral memory

This package tests whether the memory hierarchy improves behavior rather than
merely reconstructing a stored field.

The nonlinear Adrianic-like field must act on a hidden context after its cue has
disappeared.  Adaptive consolidation decides which experiences deserve durable
storage, rejects short distractors, and uses redundant/parity-protected banks.

Comparisons:
- adaptive consolidation + parity;
- periodic consolidation + parity;
- working memory only;
- no memory.

See results.json and V316_SPEC.md.
